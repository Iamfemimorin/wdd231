WDD 231 W01 Course Home Page starter

1. Extract this folder and copy its contents into the ROOT of your existing wdd231 GitHub repository.
2. Check your GitHub repository URL and update the GitHub link in index.html (the current link is a generic GitHub profile URL).
3. Replace images/profile-placeholder.svg with your own optimized photo. Keep each raster image at 125 kB or less.
4. IMPORTANT: Replace the sample course objects in scripts/courses.js with the exact official array supplied by your WDD 231 course at:
   https://byui-cse.github.io/wdd231-ww-course/week01/courses.js
   The six entries here are a starter example, not a verified copy of the official source. Confirm each course title, number and credit value.
5. Confirm completed:true only for courses you have personally completed. The starter marks CSE 110 as completed based on previously shared coursework; change it if needed.
6. Open the repository folder in VS Code, run index.html with Live Server, and test at mobile and desktop widths.
7. Run the BYU-I WDD231 W01 audit and Lighthouse. This project has not been run through your browser's audit tools, so no score is guaranteed.
8. Commit and push to GitHub. Your page URL will be https://YOUR-GITHUB-USERNAME.github.io/wdd231/

The Chamber and Final links point to placeholder paths. Update them when those projects are created.
